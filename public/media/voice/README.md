# Voice lines

Optional. Drop one file per level here, named after the level id, and the "Listen" button appears
on that level's cleared card:

```
met.m4a  map.m4a  moments.m4a  puzzle.m4a  gomoku.m4a  draw.m4a  stars.m4a  ring.m4a
```

Record on a phone (Voice Memos exports .m4a), keep each under ~15 seconds. Missing files are
simply skipped; nothing else needs changing.
