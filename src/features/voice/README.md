# Voice notes (the mailbox)

The red mailbox by the fountain in the town holds the voice notes we send each other. Bump it
and the talk box lists the other one's notes, newest first, as play buttons (date and length).
`notes.ts` is the list, generated by `npm run notes` from the files in `public/media/voice/notes/`
(name them `<date>-<sender>.m4a`; its README says how to get a file out of WeChat). The per-level lines in `public/media/voice/<level>.m4a` are a
separate thing (the cleared card's Listen button).
